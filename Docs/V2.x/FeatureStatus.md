# v2.0.0 feature status

This page describes the **current development working tree**, not a stable release promise. An implemented API can still need environment-specific verification before production use. The [roadmap](Roadmap.md) separates completed foundations from remaining v2.0.0 work packages. The [v1.x public docs](https://squehub.com/docs/v1.x) describe the published generation; examples from that site must not be assumed to be v2 APIs.
